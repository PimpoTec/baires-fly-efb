📲 Instalar como App en iPad / Celular

• iPhone / iPad (Safari): Abrí el link de GitHub Pages, tocá el botón Compartir ⍗ (arriba en iPad, abajo en iPhone) y elegí "Agregar a pantalla de inicio".
• Android (Chrome): Tocá ⋮ y elegí "Instalar aplicación". Se instala como app independiente con ícono propio.

Sincronización Automática vía GitHub Gist No vinculado

Pegá un GitHub Personal Access Token (classic) (empieza con ghp_ y tiene permiso gist) para sincronizar automáticamente tu flota y bitácora entre la PC, el iPad y el celular. Dejá el Gist ID vacío para crearlo automáticamente.
